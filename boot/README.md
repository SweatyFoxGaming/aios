# Phoenix OS - Bootloader

This module handles the integration with the bootloader (Limine).

## Strategy

- Use **Limine** as the primary bootloader for both UEFI and BIOS support.
- Integrate the Limine Rust crate for protocol handling.
- Automate the creation of bootable ISO/disk images.

## Current Status

- Strategy defined.
- Integration planned for Milestone 2.
